Prove-It Bond: local demo app

Local only (127.0.0.1). Devnet only. A $0.25 refundable bond is posted with a proof input file; a sandbox runs it under AddressSanitizer.

Approve this payment?

The demo agent will pay up to $0.25 from the demo wallet. If the report is reproduced or inconclusive the bond is returned ($0 settled). If it is not reproduced the bond is forfeited ($0.25 settled). Your click here is the approval.

Static page: no framework, no CDN, no web fonts, no external requests (CSP blocks them). Explorer links are plain links you click yourself.
